# apmw user guide

`apmw` wraps the [apm](https://github.com/microsoft/apm) CLI: it runs the real `apm install`
or `apm update` and then places the OpenCode plugins of the installed packages.

The numbered list is the order of the guide and the sidebar of the documentation site.

1. [Getting started](getting-started.md): install `apmw`, the commands and their flags.
2. [Global install](global-install.md): the whole apm-hub skill set installed globally, with the OpenCode plugin.
3. [Development](development.md): working on `apmw` itself.

Releases and prebuilt executables: [GitHub Releases](https://github.com/GravionLabs/apmw/releases) ·
changes: [CHANGELOG](https://github.com/GravionLabs/apmw/blob/main/CHANGELOG.md).
